# UI UX Pro Max integration

This project reserves this location for the UI UX Pro Max Claude skill/configuration.

Recommended setup from the UI UX Pro Max project:
```powershell
npm install -g uipro-cli
uipro init --ai claude
```

After installing the CLI skill, let Claude use its generated rules for the design system. Do not treat this README as the full skill implementation; the CLI should install the current official skill files.
