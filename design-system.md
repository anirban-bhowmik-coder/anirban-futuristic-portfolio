# ANIRBAN — DESIGN SYSTEM

## Visual language
Editorial + futuristic + AI laboratory + interactive product showcase.

## Reference ingredients
- off-white dotted grid
- oversized editorial serif
- clean sans-serif UI
- dark floating product windows
- rounded corners
- restrained shadows
- premium whitespace
- cinematic motion
- 3D kinetic mesh

## Component rule
21st.dev components are source material. Copy useful components into `src/components/ui/`, then restyle them to match this system.

## Motion rule
Motion should explain hierarchy and interaction. Avoid animating every element.

## 3D rule
Three.js/R3F should create meaningful depth: kinetic mesh, particles, nodes, orbital structures. Reduce complexity on mobile.

## Accessibility
Respect `prefers-reduced-motion`, keyboard navigation, readable contrast and semantic HTML.
